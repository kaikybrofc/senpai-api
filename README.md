# Senpai API

API do projeto **Senpai**.

## Sobre

Este repositório contém a implementação da API do Senpai. Esta documentação será ampliada conforme endpoints, autenticação e requisitos de execução forem confirmados no código-fonte.

## Começando

1. Clone o repositório:
   ```bash
   git clone https://github.com/kaikybrofc/senpai-api.git
   cd senpai-api
   ```
2. Consulte os arquivos de configuração e o manifesto de dependências do projeto para identificar a versão do runtime e os comandos de instalação e inicialização.
3. Configure as variáveis de ambiente exigidas pela aplicação antes de executá-la. Não publique tokens, senhas ou chaves no repositório.

## Desenvolvimento
